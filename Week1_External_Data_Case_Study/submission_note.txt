Week 1 updated submission description (for the internship portal):

I am submitting a strengthened version of my Week 1 fashion data strategy, with an additional independently reproducible external-data case study that addresses earlier evaluation feedback. The Word report retains the original strategy, KPI definitions, inventory and trend forecasting analysis, six-week implementation plan, risk controls, and references, while adding an empirical appendix demonstrating the integration of two publicly available World Bank indicators for India. I obtained country-year observations for individuals using the Internet (% population) and urban population (% population), for 2020–2025. The accompanying Python script validates country codes, year types, percentage ranges, missing values, and duplicate keys, joins the two independent series using country and year, generates a six-row analysis-ready table, computes year-to-year context measures, and exports a labelled chart and JSON results. Observed World Bank data show Internet usage rising from 43.41% in 2020 to 70.00% in 2025, a 26.59 percentage point change; the urban-population share increased from 34.13% to 35.69%, a 1.56 point change. These are not claimed as apparel sales or forecasts. The report then explains how this contextual evidence can help prioritise a small mobile-first retail marketing experiment, including an explicitly hypothetical worked funnel calculation with clearly stated assumptions rather than unsupported performance claims. The recommended action is to measure actual local conversions and return-adjusted profitability through a controlled pilot before deciding whether to invest further. Source URLs, preprocessing rules, observed values, joined CSV, Python scripts, reproducibility instructions and five automated tests are visible in the GitHub repository. This addition demonstrates a concrete data-acquisition-to-business-decision workflow while preserving limitations around geographic granularity, correlation, causality, data freshness and consumer privacy.
