# EVALUATOR — Week 3 — EDA and Visualization in Fashion Trends

Real U.S. Census retail dataset (92 monthly records), five charts, robust outlier screen, seasonality, distribution, correlated nested series, practical limitations.

**Open the report:** [Week3_Fashion_EDA_and_Visualization_Report.docx](Week3_Fashion_EDA_and_Visualization_Report.docx)

**Inspect the Python:** [src/eda.py](src/eda.py)

**Reproduce:** `pip install -r requirements.txt`, `python run_analysis.py`, `python -m unittest discover -s tests -v`.

**Verify outputs:** outputs/eda_findings.json, outputs/annual_summary.csv, outputs/seasonality_by_month.csv, outputs/robust_outliers_yoy.csv, and five PNGs in assets/

The primary dataset is a frozen 15 October 2026 FRED table of real published U.S. national clothing sales. No synthetic outcomes are presented as actual company results; interpretation is sector-level, not an Indian shop forecast.
